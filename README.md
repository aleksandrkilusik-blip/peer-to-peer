# Пліч-о-пліч

Сайт довідок «рівний рівному» для поранених військових і ветеранів: що робити далі, коли ніхто нічого не пояснює. Пишемо від побратима, який сам пройшов цей шлях. Назва «Пліч-о-пліч» робоча.

## Рамка проєкту

- Тільки українською, англійської версії поки немає.
- Окремий особистий проєкт. Він не пов'язаний із місією УДХ і не є її ветеранським сайтом.
- Принцип «рівний рівному»: кожна картка йде за одним шаблоном і одним тоном.
- Сайт не замінює лікаря чи юриста. Медичні та психологічні картки публікуємо лише після перевірки фахівцем.
- Публікація тільки після явного «так» власника проєкту.

## Структура сайту

- Головна за станами: «Що в тебе зараз?» ведеться до першої дії.
- Три категорії: повернення в цивільне життя; здоров'я (поранення, кукса, протез); голова (психологічна допомога).
- Окремі сторінки: «Знайти своїх», «Джерела», «Про сайт».
- Кризова сторінка з кнопкою SOS на кожній сторінці. Кризові номери додаємо лише після того, як їх продзвонено.
